# موقع محامص ومطاحن أبو عطية

موقع عرض منتجات للزبائن والتجار – جنين، فلسطين.

- **صفحة واحدة سريعة** (HTML + CSS + JavaScript) بدون سيرفر، تشتغل مجاناً على GitHub Pages.
- **طلب الجملة**: التاجر يختار الأصناف والكميات، ويوصل الطلب جاهز على واتساب الشركة.
- الصور مضغوطة WebP بمقاس العرض (المجموع ≈ 1.5MB).

## تعديل المنتجات
كل المنتجات والبهارات والماكينات وأرقام التواصل في ملف واحد: `js/data.js`.
لإضافة منتج: ضيف سطر في `PRODUCTS` وحط صورته باسم الـ `id` في `img/products/` (WebP بعرض 380px).

## التشغيل محلياً
```
npx http-server -p 5173
```
